# CO2_Optuna_Prediction_JGRAGU
Code, data and results for predicting daily atmospheric CO₂ at Mauna Loa and Barrow using trend-aware preprocessing (training-only quadratic detrending), chronological validation and Optuna-tuned DT, RF, XGBoost, LSTM and BiLSTM models. Companion to a JGR: Atmospheres paper.
